### 1. 동작 설계 및 핵심 규칙

1. **원본 비파괴 처리:** 크롬에서 내보낸 백업 `bookmarks.html`을 입력으로 받아 정리된 새 `bookmarks_cleaned.html`을 출력합니다. 기존 북마크나 원본 백업 파일은 직접 덮어쓰지 않습니다.
2. **URL 정규화 및 중복 제거:**
* 프로토콜(`http`/`https`) 및 호스트 소문자화, 기본 포트(`:80`, `:443`) 제거, 불필요한 추적 파라미터(`utm_*`, `fbclid`, `gclid`, `igshid`, `mc_cid`, `mc_eid`, `ref`, `ref_src`) 제거를 수행합니다.
* 정규화된 URL이 이미 등장한 경우 중복으로 간주하고 제거합니다(필요 시 기존 폴더에 이미 있는 항목을 우선 남기도록 확장 가능).

3. **기존 폴더 기준 매칭:**
* 백업 파일에 이미 존재하는 폴더 경로 목록(`existing_folders`)을 추출합니다.
* **1차 규칙 매칭:** 설정한 규칙(`rules.json`, 도메인/제목 키워드 → 기존 폴더 경로)으로 먼저 매칭합니다.
* **2차 로컬 AI 매칭(선택):** 규칙에 걸리지 않는 항목만 로컬 Ollama(예: `qwen2.5` 또는 `llama3.1` 등 로컬 설치 모델)에 **기존 폴더 목록 중 하나만 선택**하도록 질의해 매칭합니다. 새 폴더 생성은 프롬프트/코드 수준에서 차단합니다.

---

### 2. 실행 절차

1. **백업 파일 준비:** 크롬 북마크 관리자(`chrome://bookmarks`) → 우측 상단 메뉴(⋮) → **북마크 내보내기**로 `bookmarks_backup.html`을 작업 폴더에 저장합니다.
2. **규칙 파일(`rules.json`) 작성:** 기존 폴더 경로와 매칭할 도메인/키워드를 정의합니다(예시는 아래 코드 블록 참고).
3. **스크립트 실행:** Python 3.10+ 환경에서 스크립트를 실행해 `bookmarks_cleaned.html`과 이동/중복 요약 리포트를 생성합니다.
4. **결과 검증 및 반영:** `bookmarks_cleaned.html`을 별도 프로필이나 테스트 환경에서 먼저 가져와 폴더 배치를 확인한 뒤, 최종적으로 크롬 북마크 관리자로 가져옵니다.

### 3. 로컬 처리용 Python 스크립트 예시

외부 API 호출 없이 로컬 파일만 처리하며, 선택적으로 로컬 [Ollama](http://localhost:11434/api/generate)를 연동할 수 있는 구조입니다.

```python
import json
import re
from pathlib import Path
from urllib.parse import parse_qsl, urlencode, urlsplit, urlunsplit
from bs4 import BeautifulSoup, Tag
import urllib.request

TRACKING_PARAMS = {
    "utm_source", "utm_medium", "utm_campaign", "utm_term", "utm_content",
    "fbclid", "gclid", "igshid", "mc_cid", "mc_eid", "ref", "ref_src"
}


def normalize_url(raw_url: str) -> str:
    url = raw_url.strip()
    parts = urlsplit(url)
    scheme = parts.scheme.lower()
    netloc = parts.netloc.lower()

    if netloc.endswith(":80") and scheme == "http":
        netloc = netloc[:-3]
    elif netloc.endswith(":443") and scheme == "https":
        netloc = netloc[:-4]

    filtered_query = [
        (k, v) for k, v in parse_qsl(parts.query, keep_blank_values=True)
        if k.lower() not in TRACKING_PARAMS
    ]
    query = urlencode(filtered_query)
    path = parts.path or "/"
    if path != "/" and path.endswith("/"):
        path = path[:-1]

    return urlunsplit((scheme, netloc, path, query, ""))


def collect_folders(dl_tag: Tag, prefix: str = "") -> list[str]:
    folders = []
    for child in dl_tag.find_all("dt", recursive=False):
        h3 = child.find("h3", recursive=False)
        sub_dl = child.find("dl", recursive=False)
        if h3 and sub_dl:
            folder_name = h3.get_text(strip=True)
            full_path = f"{prefix}/{folder_name}" if prefix else folder_name
            folders.append(full_path)
            folders.extend(collect_folders(sub_dl, full_path))
    return folders


def match_by_rules(title: str, url: str, rules: list[dict], valid_folders: set[str]) -> str | None:
    haystack = f"{title} {url}".lower()
    for rule in rules:
        target = rule.get("folder", "")
        if target not in valid_folders:
            continue
        keywords = [kw.lower() for kw in rule.get("keywords", [])]
        domains = [dm.lower() for dm in rule.get("domains", [])]
        host = urlsplit(url).netloc.lower()
        if any(dm in host for dm in domains) or any(kw in haystack for kw in keywords):
            return target
    return None


def process_bookmarks(
    input_html: Path,
    output_html: Path,
    rules_path: Path,
    use_ollama: bool = False,
    ollama_model: str = "qwen2.5:7b"
) -> dict:
    html_text = input_html.read_text(encoding="utf-8", errors="ignore")
    soup = BeautifulSoup(html_text, "html.parser")
    root_dl = soup.find("dl")
    if not root_dl:
        raise ValueError("유효한 북마크 DL 구조를 찾을 수 없습니다.")

    rules = json.loads(rules_path.read_text(encoding="utf-8")) if rules_path.exists() else []
    existing_folders = collect_folders(root_dl)
    valid_folder_set = set(existing_folders)

    seen_urls: set[str] = set()
    stats = {"total_links": 0, "duplicates_removed": 0, "matched_by_rule": 0, "matched_by_ai": 0, "unmatched": 0}

    for a_tag in root_dl.find_all("a"):
        raw_href = a_tag.get("href", "")
        if not raw_href.startswith(("http://", "https://")):
            continue

        stats["total_links"] += 1
        norm_url = normalize_url(raw_href)
        if norm_url in seen_urls:
            stats["duplicates_removed"] += 1
            parent_dt = a_tag.find_parent("dt")
            if parent_dt:
                parent_dt.decompose()
            continue

        seen_urls.add(norm_url)
        title = a_tag.get_text(strip=True)

        matched = match_by_rules(title, norm_url, rules, valid_folder_set)
        if matched:
            stats["matched_by_rule"] += 1
            a_tag["data-suggested-folder"] = matched
        elif use_ollama:
            ai_folder = match_by_ollama(title, norm_url, existing_folders, model=ollama_model)
            if ai_folder:
                stats["matched_by_ai"] += 1
                a_tag["data-suggested-folder"] = ai_folder
            else:
                stats["unmatched"] += 1
        else:
            stats["unmatched"] += 1

    output_html.write_text(str(soup), encoding="utf-8")
    return stats


if __name__ == "__main__":
    summary = process_bookmarks(
        input_html=Path("bookmarks_backup.html"),
        output_html=Path("bookmarks_cleaned.html"),
        rules_path=Path("rules.json"),
        use_ollama=False,
        ollama_model="qwen2.5:7b"
    )
    print(json.dumps(summary, indent=2, ensure_ascii=False))

```

  },
  {

### 4. 추가 고려 사항 및 한계

* **실제 트리 이동 로직:** 위 예시는 중복 제거와 함께 각 링크에 `data-suggested-folder` 속성을 기록해 검토하기 쉽게 만든 기본 골격입니다. 매칭 결과를 확인한 뒤 해당 폴더 `<DL>` 아래로 `<DT>` 노드를 실제 이동시키는 로직을 추가하면 완성된 트리 형태로 출력할 수 있습니다.
* **크롬 북마크 가져오기 동작:** 크롬에서 HTML 북마크를 가져오면 `"가져온 북마크"` 폴더 아래에 구조가 생성되므로, 기존 북마크와 합칠 때는 중복 폴더가 생기지 않도록 최종 배치 위치를 한 번 더 점검해야 합니다.
