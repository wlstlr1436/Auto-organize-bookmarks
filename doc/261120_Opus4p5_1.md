# 크롬 북마크 백업 HTML 파일 정리 프로그램 개발 계획서

## 1. 프로젝트 개요

### 1.1 목적
로컬 PC 환경에서 크롬 북마크 백업 HTML 파일을 분석하여 중복 URL을 정규화 및 제거하고, 기존 폴더 구조를 유지하면서 정리된 북마크 파일을 생성하는 프로그램을 개발합니다.

### 1.2 핵심 요구사항
- **완전한 오프라인 동작**: 외부 네트워크 연결 없이 로컬에서만 실행
- **URL 정규화**: 다양한 형태의 동일 URL을 표준화
- **중복 제거**: 정규화된 URL 기준으로 중복 항목 식별 및 제거
- **폴더 구조 보존**: 기존 북마크 폴더 경로 매칭 및 유지

## 4. 데이터 모델 설계

### 4.1 핵심 데이터 클래스

```python
from dataclasses import dataclass, field
from typing import Optional, List
from datetime import datetime

@dataclass
class Bookmark:
    """개별 북마크 항목"""
    id: str                          # 고유 식별자
    title: str                       # 북마크 제목
    original_url: str                # 원본 URL
    normalized_url: str              # 정규화된 URL
    add_date: Optional[datetime]     # 추가 날짜
    icon: Optional[str]              # 아이콘 데이터 (base64)
    folder_path: str                 # 폴더 경로 (예: "/북마크바/개발/Python")
    
@dataclass
class Folder:
    """북마크 폴더"""
    name: str                        # 폴더명
    path: str                        # 전체 경로
    parent: Optional['Folder']       # 부모 폴더
    children: List['Folder'] = field(default_factory=list)
    bookmarks: List[Bookmark] = field(default_factory=list)
    add_date: Optional[datetime] = None
    last_modified: Optional[datetime] = None

@dataclass
class DuplicateGroup:
    """중복 URL 그룹"""
    normalized_url: str              # 정규화된 URL
    bookmarks: List[Bookmark]        # 중복된 북마크 목록
    selected_index: int = 0          # 유지할 북마크 인덱스
```

### 5.2 정규화 규칙 상세

| 단계 | 처리 내용 | 예시 |
|------|-----------|------|
| **스키마** | 소문자 변환, 기본값 처리 | `HTTP://` → `http://` |
| **호스트** | 소문자, www 처리, IDN 변환 | `WWW.Example.COM` → `example.com` |
| **포트** | 기본 포트 제거 | `:80`, `:443` 제거 |
| **경로** | 상대 경로 해석, 후행 슬래시 | `/a/../b/` → `/b` |
| **쿼리** | 키 정렬, 빈 값 처리 | `?b=2&a=1` → `?a=1&b=2` |
| **프래그먼트** | 설정에 따라 제거/보존 | `#section` → (제거) |

```python
    ("https://example.com:443/", "https://example.com/"),
    
    # 추적 파라미터 제거
    ("http://example.com?utm_source=google&id=1", "http://example.com?id=1"),
    
    # 경로 정규화
    ("http://example.com/a/../b/./c", "http://example.com/b/c"),
    
    # 쿼리 파라미터 정렬
    ("http://example.com?z=1&a=2", "http://example.com?a=2&z=1"),
    
    # 프래그먼트 처리
    ("http://example.com/page#section", "http://example.com/page"),
    
    # 인코딩 정규화
    ("http://example.com/%7Euser", "http://example.com/~user"),
]
```
